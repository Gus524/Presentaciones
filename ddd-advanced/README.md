# Presentation: DDD Avanzado & Arquitectura Hexagonal en C# .NET 10

Presentación técnica interactiva en **Slidev** sobre **Domain-Driven Design (DDD) Avanzado, Event-Driven Architecture (EDA) y Arquitectura Hexagonal** enfocada en sistemas financieros de Beneficios, Préstamos y Ahorros.

## 🚀 Cómo Ejecutar la Presentación con Bun

Asegúrate de tener instalado [Bun](https://bun.sh/).

```bash
# 1. Instalar dependencias con Bun
bun install

# 2. Iniciar el servidor de desarrollo e interactuar en el navegador
bun run dev
```

O ejecutar directamente sin instalación previa del CLI:

```bash
bunx slidev slides.md --open
```

## 📚 Estructura de la Presentación
- **slides.md**: Diapositivas principales escritas en Markdown nativo de Slidev con diagramas Mermaid y código C# 14 / .NET 10.
- **docs/**: Documentación técnica detallada y mapa de Bounded Contexts.
